Core Systems

EVERYTHING YOU
NEED TO BUILD

Aronno Engine ships with all the foundational systems of a modern game engine — from a fully threaded render pipeline to a drag-and-drop asset workflow.

01
Scene · GameObject · Components

Familiar, flexible ECS-style scene hierarchy with full component attachment, nested GameObjects, and runtime spawning.

02
C++ Scripting

Maximum control and performance. Write game logic directly in C++ — no scripting overhead, no virtual machine.

03
Asset System + .meta Files

Every asset gets a metadata sidecar — persistent UUIDs, import settings, and dependency tracking baked in from day one.

04
Graph-Based Animation

Node-graph animation system for blending, state machines, and complex character motion — with a dedicated asset editor.

05
PhysX Physics

Industry-standard NVIDIA PhysX integration for rigid bodies, collision shapes, triggers, and in-editor wireframe debugging.

06
FBX + Custom Mesh Format

Import industry-standard FBX files or use the engine's optimized static mesh format for faster runtime loading.

07
Asset-Based UI System

Define UI layouts as assets — menus, HUDs, and overlays built visually and loaded at runtime without code recompilation.

08
Multithreaded Architecture

Main thread and dedicated render thread running in parallel — no blocking, no stalls, smooth frame delivery.

09
Frustum Culling

Per-frame frustum culling keeps the GPU busy with only what's visible — efficient for large, complex scenes.

Engine Architecture

HOW IT'S BUILT

Aronno Engine is designed around a clean separation between the main simulation thread and a dedicated rendering thread — decoupling game logic from GPU submission for maximum efficiency.

The scene hierarchy follows a GameObject → Component model, keeping code modular while remaining fully native C++. No scripting VM overhead, no reflection magic.

Assets are first-class citizens. Every resource has a UUID-backed .meta file that persists import settings and enables stable references across scenes and prefabs.

Editor

BUILT WITH
THE ENGINE ITSELF

Aronno Editor is not a separate application — it's the engine running in editor mode. Every panel, every widget, every gizmo is rendered by the same pipeline used in-game.

01
Scene Editing

Full Scene, GameObject, and Component editing with transform gizmos, hierarchy panel, and properties inspector.

02
In-Editor Play

Hit play and your game runs inside the editor. Stop and your scene is exactly as you left it.

03
Drag & Drop Prefabs

Drag prefab assets from the browser into the scene. Edit and propagate changes back to the prefab asset.

04
UI Asset Editor

Visual editor for building UI layout assets — menus, HUDs, and overlays without writing code.

05
Animation Graph Editor

Node-based graph editor for authoring animation state machines and blending logic.

06
Physics Debug View

Toggle wireframe overlay to see all colliders and physics shapes overlaid on the live scene.

07
Material Editor

Simple PBR material editor for setting surface properties directly on material assets.

08
Drag & Drop Import

Drop FBX or texture files directly into the editor. Assets are imported, processed, and .meta files generated automatically.
